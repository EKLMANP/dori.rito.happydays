# 營銷部門

## 概述

這個部門負責 Dori & Rito Happydays 的內容創作、SEO 優化、以及客戶溝通。目標是提升品牌知名度、吸引潛在客戶、並維持與現有客戶的良好關係。

## 📝 內容創作 (content/)

### 部落格 (blogs/)
- **目的**：提供有價值的訓犬知識，建立專業形象
- **主題**：訓犬技巧、行為問題解決、案例分享
- **發布頻率**：每週 1-2 篇
- **命名規範**：`blog-##-topic-name.md`

**現有文章**：
- 高敏感狗狗照顧指南
- 分離焦慮處理方法
- 護食行為矯正技巧

### 電子報 (newsletters/)
- **目的**：定期與客戶保持聯繫，分享實用資訊
- **內容類型**：訓犬小技巧、案例分享、最新課程資訊
- **發布頻率**：每週一次
- **命名規範**：`newsletter-##-topic-name.md`

**現有電子報**：
- 安定訊號識別
- 分離焦慮問題
- 牽繩拉扯行為

### 郵件庫存 (email-inventory/)
- **目的**：存檔已發送的郵件內容，方便重複使用和參考
- **內容類型**：教育性文章、客戶案例、專題指南

**現有內容**：
- 如何建立毛孩的自信心
- 狗狗知道指令卻不做的原因
- 狗狗聲音敏感處理方法
- 高敏感狗狗陪伴指南

## 📧 郵件文案工具 (email-copywriter/)

**功能**：
- 使用 AI 協助創作高質量的郵件內容
- 與 Notion 集成管理郵件庫存
- 透過 Telegram Bot 操作

**主要文件**：
- `email_bot.py` - Telegram Bot 介面
- `notion_client.py` - Notion API 集成
- `dori-rito-copywriter-skill.md` - AI 技能說明

**使用方式**：
1. 透過 Telegram 發送郵件創作請求
2. AI 根據品牌風格和目標受眾生成內容
3. 審核和修改
4. 保存到 Notion 和本地庫存

**部署**：
- 使用 Railway 部署
- 參考 `railway.toml` 和 `Procfile` 配置

## 📊 SEO 報告 (seo-reports/)

**目的**：追蹤網站 SEO 表現，優化內容策略

**報告內容**：
- 關鍵字排名變化
- 流量分析
- 內容表現評估
- 優化建議

**命名規範**：`YYYY-W##-seo-weekly-report.md`

**現有報告**：
- 2026-W08 每週 SEO 報告

## 🎯 內容策略

### 目標受眾
1. **新手狗主人**：需要基礎訓犬知識
2. **有問題行為的狗主人**：尋求解決方案
3. **追求深度訓練的狗主人**：想提升與狗狗的關係

### 內容主題
- 訓犬基礎知識
- 行為問題解決（吠叫、拉扯、分離焦慮等）
- 正向訓練方法
- 人犬關係建立
- 案例分享與成功故事

### SEO 關鍵字策略
- 主要關鍵字：訓犬、狗狗訓練、行為矯正
- 長尾關鍵字：如何訓練狗狗、分離焦慮怎麼辦
- 地區性關鍵字：台北訓犬、台灣訓犬師
