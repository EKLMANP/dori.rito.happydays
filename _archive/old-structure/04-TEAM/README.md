# 團隊協作

## 概述

這個部門存放團隊協作相關的資源，包括 AI 角色 Prompts、團隊規範、以及協作工具說明。

## 🎭 AI 角色 Prompts (prompts/)

為了讓 AI 工具（Claude Code、Antigravity 等）更好地理解不同職位的需求和工作方式，我們為每個角色創建了專門的 Prompt 定義。

### 現有角色

#### 1. 負責人 (dr-head.md)
- **視角**：全局戰略、業務發展
- **關注點**：營收、客戶滿意度、團隊管理
- **決策風格**：數據驅動、長期規劃
- **使用時機**：需要做出戰略決策、評估新項目、資源分配

#### 2. 訓犬師 (dr-trainer.md)
- **專業領域**：犬類行為學、訓練方法
- **關注點**：訓練效果、客戶體驗、案例記錄
- **溝通風格**：專業但平易近人、耐心解釋
- **使用時機**：設計訓練課程、解決行為問題、撰寫技術內容

#### 3. 行銷人員 (dr-mkt.md)
- **專業領域**：內容行銷、社群經營、品牌建立
- **關注點**：流量、轉換率、品牌形象
- **溝通風格**：親切、有感染力、故事性強
- **使用時機**：內容創作、行銷策略、社群互動

#### 4. SEO 專員 (dr-seo.md)
- **專業領域**：搜尋引擎優化、關鍵字研究
- **關注點**：排名、流量、內容優化
- **工作方式**：數據分析、持續優化、測試驗證
- **使用時機**：SEO 分析、關鍵字策略、內容優化建議

#### 5. 客服人員 (dr-cs.md)
- **專業領域**：客戶溝通、問題解決
- **關注點**：客戶滿意度、回應速度、問題解決率
- **溝通風格**：溫暖、同理心、問題導向
- **使用時機**：客戶諮詢回覆、FAQ 整理、客訴處理

#### 6. 設計師 (dr-designer.md)
- **專業領域**：視覺設計、品牌呈現
- **關注點**：美感、一致性、使用者體驗
- **工作方式**：視覺化思考、細節導向
- **使用時機**：視覺設計、品牌素材、UI/UX 設計

## 💡 如何使用 AI 角色 Prompts

### 在 Claude Code 中使用

1. **開始對話時指定角色**：
   ```
   請以 Dori & Rito 訓犬師的角色，幫我設計一個針對分離焦慮的訓練課程。
   ```

2. **參考角色文件**：
   ```
   請閱讀 04-TEAM/prompts/dr-trainer.md，然後以該角色回答客戶的問題。
   ```

3. **多角色協作**：
   ```
   我需要設計一個新的訓練課程套餐：
   - 請訓犬師設計課程內容
   - 請行銷人員撰寫宣傳文案
   - 請設計師建議視覺呈現
   ```

### 在 Antigravity 中使用

Antigravity 會自動讀取 `.config/ai-tools/antigravity/` 中的配置，使用對應的角色 Prompt。

### 自定義角色

如果需要新增角色，請：
1. 複製現有的角色文件作為模板
2. 修改角色定義、專業領域、關注點
3. 保存為新的 `.md` 文件
4. 更新本 README

## 🤝 團隊協作最佳實踐

### 溝通原則
- **清晰明確**：說明需求、目標、期望結果
- **及時反饋**：有問題立即溝通，不要憋著
- **相互尊重**：尊重不同專業的意見和建議

### 文件管理
- **命名規範**：使用清晰的文件名
- **版本控制**：使用 Git 管理變更
- **文檔更新**：修改後更新相關說明文檔

### 任務管理
- **使用 Notion**：任務分配、進度追蹤
- **定期檢討**：每週檢討進度和問題
- **知識分享**：記錄經驗和學習

## 📋 團隊會議

### 每日站會（Daily Standup）
- **時間**：每天早上 10:00
- **時長**：15 分鐘
- **內容**：
  - 昨天完成了什麼
  - 今天計劃做什麼
  - 遇到什麼問題

### 每週回顧（Weekly Review）
- **時間**：每週五下午
- **時長**：1 小時
- **內容**：
  - 本週成果回顧
  - 問題檢討
  - 下週計劃

### 月度策略會議（Monthly Strategy）
- **時間**：每月第一個週一
- **時長**：2 小時
- **內容**：
  - 上月成效分析
  - 本月目標設定
  - 策略調整
