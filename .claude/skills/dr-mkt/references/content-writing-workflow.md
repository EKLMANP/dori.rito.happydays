# DR-MKT 內容撰寫工作流程

## 觸發條件
使用者說：`請依據 Notion 上的 XXXX - SEO 關鍵字研究，產出 N 篇 XXXX 系列的 [部落格/電子報/社群貼文]`

## 執行步驟

### Step 1：讀取 SEO 研究
用 `notion-fetch` 讀取使用者指定的 SEO 關鍵字研究頁面，擷取：
- 核心關鍵字（主/副）及搜尋量
- 內容矩陣建議（旗艦文章、叢集文章標題草案）
- 長尾關鍵字清單
- 執行策略建議

### Step 2：確認產出需求
向使用者確認（若未提供）：
- **格式**：部落格 / 電子報 / 社群貼文
- **篇數**：N 篇
- **系列命名**：例如「吠叫系列」「豐富化遊戲系列」
- **CTA 方向**（選填）：加入社群 / 報名課程 / 預約諮詢

### Step 3：撰寫內容
依照以下規範撰寫：
- 品牌語氣和禁止用詞 → `references/writing-guidelines.md`
- 格式模板 → `references/notion-publishing.md`

每篇文章依序產出，確保：
- 關鍵字在文中用**粗體**標記，首段必出現
- 部落格 2,000-3,500 字、電子報 500-800 字
- 所有 CTA 統一導向：`https://tally.so/r/KY55Bg`
- 部落格末段包含 DR-Designer 視覺設計提案區塊（含 AI Prompt）
- 部落格末段包含 Ghost 發布資訊區塊

### Step 4：電子報固定結尾
所有電子報必須以以下內容結尾（不可修改）：

```
我們下封信見。
Dori & Rito
Happy dog, happy life 🐾

P.S. 如果你覺得這篇文章對你有幫助，歡迎轉發給同樣有這個困擾的朋友。讓更多毛孩和毛爸媽知道，這條路上你們並不孤單。
```

### Step 5：逐篇寫入 Notion
使用 `notion-create-pages` 寫入資料庫：

```
parent: { data_source_id: "30f17e11-503d-801a-820f-000beadd6413" }
pages: [{
  properties: {
    "主題": "[系列名] [序號]【部落格】[標題]",  // 或【電子報】
    "date:Date:start": "[YYYY-MM-DD]",
    "date:Date:is_datetime": 0,
    "Category": "[\"Blog\"]",       // 或 "[\"Email\"]"
    "Tags": "[\"標籤1\", \"標籤2\"]",  // 從資料庫既有選項中選擇
    "status": "Not started",
    "Parent item": "[SEO 關鍵字研究頁面 URL]"
  },
  content: "[完整文章 Markdown]"
}]
```

#### 命名規則
- 部落格：`[系列名] [序號]【部落格】[標題]`
  - 例：`吠叫系列 1【部落格】狗狗一直叫怎麼辦？聽懂 6 種吠叫語言，用對方法才有效`
- 電子報：`[系列名] [序號]【電子報】[標題]`
  - 例：`吠叫系列 1【電子報】狗狗不是在亂叫，而是牠正在跟你說這6件事`

#### 屬性設定規則
- `status`：固定為 `Not started`
- `Parent item`：必須設定為對應的 SEO 關鍵字研究頁面 URL
- `Category`：`Blog` 或 `Email`（不可同時選兩個）
- `Tags`：從資料庫既有選項中選擇最貼近的標籤（可多選）

### Step 6：完成通知
逐篇告知使用者已建立，提供每篇 Notion 頁面連結和概要。
