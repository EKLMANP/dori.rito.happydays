## 1. 品牌核心 Brand Core

### 1.1 品牌故事
2024 年，KPA / CATCH 正向訓練雙認證的 Eric & Pennee 領養了兩隻米克斯狗狗 **Dori（多莉）** 與 **Rito（多姿）**。兩隻狗陪他們走過敏感、焦慮、反應性行為的挑戰，也讓他們看見：**台灣飼主缺的不是「更嚴厲的方法」，而是被科學理解、被同理對待的陪伴。**

Dori & Rito Happydays 因此誕生 —— 把「快樂的每一天 (Happydays)」還給每一對人犬。

### 1.2 使命 / 願景 / 核心理念

| 面向 | 敘述 |
|---|---|
| **Mission 使命** | 用科學為基礎、以正向為核心的訓練方法，協助敏感／焦慮／反應性狗狗重新找回平靜，讓飼主不再獨自面對。 |
| **Vision 願景** | 成為華語世界最值得信任的正向訓犬品牌，重新定義「好狗狗」的標準 —— 從「聽話」到「被理解」。 |
| **Core Belief 核心信念** | 「訓練卡關不是你的錯，是資訊不夠貼近你們的狀況。」沒有壞狗，只有被誤解的狗。 |

### 1.3 品牌個性 Brand Personality

若將品牌擬人化，DRH 是一位「**拿到國際認證的訓犬師朋友**」—— 而不是教科書，也不是居高臨下的專家。

| 維度 | 定位（★ 越多越強） |
|---|---|
| 溫暖 Warm ─ 冷靜 Cool | ★★★★☆ 偏溫暖 |
| 專業 Expert ─ 親切 Friendly | ★★★★★ 兩者並重 |
| 嚴肅 Serious ─ 輕鬆 Playful | ★★★☆☆ 偏穩重 |
| 傳統 Classic ─ 前衛 Modern | ★★★★☆ 偏現代 |
| 華麗 Luxe ─ 樸實 Earthy | ★★☆☆☆ 偏自然樸實 |

**一句話定性**：溫暖而有底氣、專業而不冰冷、現代而不浮躁。

### 1.4 品牌承諾（對外口號庫）
可混用／改寫，用於 banner、hero、簡報封面、社群貼文。

- **主標語**：以科學為基礎 ・ 以正向為核心 🐾
- **副標語候選**：
  - 「100% 無恐懼訓練」
  - 「終於，你和你的敏感狗狗也可以安心散步、快樂相處」
  - 「不是因為你不夠努力，而是那些方法，根本不是為你的狗設計的。」
  - 「讓每一對人犬，找到最舒適的生活節奏。」

## 2. Logo 系統

### 2.1 主 Logo
- **檔案位置**：`https://iili.io/qf6QsVe.png`（線上版）；設計原檔應存於 `03-Design/brand-assets/logo/`
- **組成**：文字標 "Dori & Rito" + 🐾 Paw Print 符號
- **風格**：Modern sans-serif wordmark，clean / friendly / approachable

### 2.2 安全區域 Clear Space
Logo 四周保留至少 = **Logo 高度的 1/2** 的空白，避免與其他元素擁擠。

### 2.3 最小尺寸 Minimum Size
- **數位**：高度 ≥ 32px（horizontal lock-up）
- **印刷**：高度 ≥ 10mm

### 2.4 Logo 使用規則

| ✅ 可以 | ❌ 不可以 |
|---|---|
| 用在 `#faedcd`(cream) / `#ffffff`(white) / `#4a4a38`(dark) 背景 | 放在低對比或花俏背景上 |
| 等比例縮放 | 任意拉伸變形 |
| 使用品牌色 `#f75000` / `#4a4a38` / 白 的官方版本 | 自行上色、加陰影、加描邊 |
| 在印刷時搭配 clear space 規範 | 把 🐾 Paw 單獨當作 logo 主體 |

## 3. 色彩系統 Color System

> 本系統**完全同步官網實際 CSS 變數**，確保所有素材與網站一致。

### 3.1 色票總覽 Full Palette

#### 主色 Primary

| Token | Hex | 用途 | 樣本 |
|---|---|---|---|
| `--color-primary` | **`#F75000`** | 品牌主 CTA、強調文字、連結、按鈕 | 🟧 signature orange |
| `--color-primary-hover` | `#C4935F` | Hover / pressed 狀態（焦糖棕） | 🟫 |
| `--color-primary-light` | `#F0D9BF` | 淡底色、hover 背景、軟性強調 | 🌼 |

#### 底色（Cream 系） Base

| Token | Hex | 用途 |
|---|---|---|
| `--color-cream` | **`#FAEDCD`** | **全站主要背景色**（溫暖米白） |
| `--color-cream-dark` | `#F5E4B0` | 區塊切換、深一階背景 |
| `--color-white` | `#FFFFFF` | 卡片 / 表單背景、需要純淨感的區塊 |

#### 輔色（Sage 自然系） Accent — Natural

| Token | Hex | 用途 |
|---|---|---|
| `--color-sage` | **`#CCD5AE`** | 輔助強調、保證章、科學／自然類徽章 |
| `--color-sage-dark` | `#A8B887` | 深鼠尾草，用於 hover 或需要層次時 |

#### 中性色 Neutral

| Token | Hex | 用途 |
|---|---|---|
| `--color-sand` | `#DEDBD2` | 次要背景、柔和分隔 |
| `--color-border` | `#E8E4D8` | 邊框、分隔線 |
| `--color-text` | **`#4A4A38`** | **主要內文文字色**（深橄欖） |
| `--color-text-muted` | `#7A7A65` | 副文、註解、meta、日期 |

### 3.2 色彩使用比例 60-30-10 原則

```
┌──────────────────── 60% ────────────────────┐
│       Cream 系（#FAEDCD / #F5E4B0）         │  ← 背景主調
└─────────────────────────────────────────────┘
┌────────────── 30% ──────────────┐
│ Text (#4A4A38) + Sand/Border    │   ← 文字、分隔、卡片
└─────────────────────────────────┘
┌── 10% ──┐
│ Orange  │  Sage accent            ← CTA、標籤、徽章
└─────────┘
```

### 3.3 可近性 Accessibility

| 文字色 / 背景 | 對比度 | WCAG |
|---|---|---|
| `#4A4A38` on `#FAEDCD` | ~9.2 : 1 | ✅ AAA |
| `#FFFFFF` on `#F75000` | ~3.8 : 1 | ⚠️ AA Large Text only |
| `#4A4A38` on `#F75000` | ~4.9 : 1 | ✅ AA（正常文字可過） |
| `#7A7A65` on `#FAEDCD` | ~4.6 : 1 | ✅ AA |

> **規則**：白字 on 主橘 **只用於 16pt / bold 以上或按鈕**；一般內文不使用白字 on 橘。

### 3.4 禁用色
- ❌ 純黑 `#000000`（太冰冷）→ 改用 `#4A4A38`
- ❌ 純灰 `#808080`（太冷）→ 改用 `#7A7A65`
- ❌ 飽和紅、寶藍、螢光色（偏離品牌溫度）

## 4. 字體系統 Typography

### 4.1 字型家族 Font Families

| 角色 | 字體 | 來源 | 用途 |
|---|---|---|---|
| **主字體 Primary** | **Noto Sans TC** | [Google Fonts](https://fonts.google.com/specimen/Noto+Sans+TC)（自由商用） | 所有繁體中文內文、標題 |
| **Fallback 回退** | PingFang TC → Microsoft JhengHei → sans-serif | 系統字 | 無法載入 Noto Sans TC 時 |
| **強調字體 Accent** | Dancing Script (600) | [Google Fonts](https://fonts.google.com/specimen/Dancing+Script) | 英文裝飾性標語、引言、署名 |
| **英文數字** | Noto Sans TC 的 Latin subset（與主字體一體） | — | 英文與數字，保持視覺一致 |

**Google Fonts import 字串**（供網站／Email HTML 使用）：
```
https://fonts.googleapis.com/css2?family=Noto+Sans+TC:wght@300;400;500;700;900&family=Dancing+Script:wght@600&display=swap
```

### 4.2 字重使用 Weight Usage

| 字重 | 權重 | 用途 |
|---|---|---|
| Light 300 | 少用 | 大尺寸引言、裝飾性大字 |
| **Regular 400** | 主用 | 內文、段落 |
| **Medium 500** | 主用 | 小標、列表項目、次級標題 |
| **Bold 700** | 主用 | H1–H3、CTA 按鈕、粗體強調 |
| Black 900 | 審慎 | Hero 視覺、關鍵數字、海報主標 |

### 4.3 字級層級 Type Scale

基準為桌機 `1rem = 16px`，行高 1.7（body）／1.3（heading）。

| 層級 | 桌機 | 手機 | 字重 | 範例 |
|---|---|---|---|---|
| Hero H0 | 56–64 px | 36–40 px | 900 | 首頁主標 |
| H1 | 40–48 px | 28–32 px | 700 | 文章主標 |
| H2 | 28–32 px | 22–24 px | 700 | 段落主標（`##`） |
| H3 | 22–24 px | 18–20 px | 700 | 步驟標題（`Step 1：... 🚪`） |
| **Body 內文** | **16–18 px** | **16 px** | **400** | 文章內文 |
| Large Lead | 18–20 px | 17 px | 400 | 段落 Lead-in |
| Small / Meta | 14 px | 13 px | 400–500 | 時間戳、分類、footer |
| Caption | 12 px | 12 px | 400 | 圖片說明 |

### 4.4 中英混排規則
- 中英之間**加半形空格**（如「Dori & Rito 是正向訓犬」）
- 中文與數字之間**加半形空格**（如「4–6 週」「1 對 1」）
- 全形符號限中文：「，。；：？！」
- 英文引號用 "smart quotes"，不用 `"` 直引號
- 破折號用半形雙 dash **——**（前後不空格）

## 5. 影像與攝影風格 Imagery

### 5.1 主題 Subjects（從上至下優先）
1. **狗狗的自然神情** —— 放鬆、嗅聞、專注、在安全空間休息（而非「坐好拍照」的擺拍）
2. **人犬互動的真實時刻** —— 散步、觸摸、訓練中的眼神交流
3. **訓練現場** —— Eric / Pennee 指導飼主的畫面
4. **生活場景** —— 家中角落、公園、散步路徑

### 5.2 色調 Tone & Grading
- **整體**：暖色調、自然光、低對比、輕度 desaturate（避免過飽和）
- **白平衡**：偏暖（與 cream `#FAEDCD` 背景協調）
- **禁用**：強烈冷色濾鏡、HDR 過曝、黑白硬調、瘦身美肌類美顏濾鏡

### 5.3 構圖 Composition
- 留白充足（與官網鬆散的節奏一致）
- 主體置於三分線，避免正中央過於呆板
- 動物視角：平視或略低角度，讓狗狗成為主角

### 5.4 影像 Do / Don't

| ✅ Do | ❌ Don't |
|---|---|
| 自然光、手持微動、紀實感 | 棚拍強打光、過度擺拍 |
| 狗狗放鬆的表情（嘴角放鬆、眼神柔和） | 露齒、壓低耳朵等壓力訊號卻標為「可愛」 |
| 展現安定訊號、嗅聞、放鬆姿態 | 服從訓練畫面、項圈拉扯 |
| 顯示 KPA / CATCH 認證徽章 | 使用未授權或模糊的認證符號 |
| 真實客戶 / 真實狗狗（經同意） | 通用的 stock photo（除非經色調統一處理） |

## 6. 圖示與 Emoji 詞彙 Iconography

### 6.1 官方 Emoji 詞庫
這些 emoji 在官網和文章中反覆使用，是品牌的「視覺輕標點」。請優先選用：

| Emoji | 語意 | 建議場景 |
|---|---|---|
| 🐾 | 品牌圖騰、簽名 | 標語結尾、logo 周邊、段落分隔 |
| ✨ | 轉變、承諾 | 「你可以期待的改變」類標題 |
| 🛡️ | 安心保證 | 「課程安心保證」類保證區 |
| 🎁 | 加值、贈禮 | 加贈、bonus、優惠 |
| 🔬 | 科學、證據 | 科學基礎類段落 |
| 🧡 | 愛與關懷 | CTA 結尾、感謝文 |
| 🚪 / 🏠 / 🐕 | 情境指示 | Step 標題（如 Step 1：淡化出門儀式 🚪）|

### 6.2 Emoji 使用規則
- **頻率**：一篇部落格文章，emoji **不超過 10 個**；社群貼文 **3–5 個**；電子報主旨 **1 個**
- **位置**：只用於標題尾端、段落分隔、列表前綴，**不放在內文句子中**
- **禁用**：😂🤣💩💔🙏🏻 等情緒過強或與品牌調性不符的 emoji

### 6.3 線性圖示 Line Icons
- 若使用插圖式 icon，建議風格：**2px 圓角線條、單色（`#4A4A38` 或 `#F75000`）、簡潔幾何**
- 推薦 icon library：[Lucide](https://lucide.dev/) / [Phosphor Icons](https://phosphoricons.com/)（regular weight）

## 7. 版型與元件 Layout & Components

### 7.1 版型原則 Layout Principles
- **Grid**：12 欄 / gutter 24px（桌機）、4 欄 / gutter 16px（手機）
- **最大內容寬度**：1280px（container）／閱讀欄位 680–720px
- **區塊間距 Section Padding**：桌機 80–120px、手機 48–64px
- **呼吸感**：寧可多留白，不要塞滿。官網刻意大量留白——保持一致。

### 7.2 圓角 Border Radius

| 尺寸 | Tailwind 對應 | 適用 |
|---|---|---|
| 6 px | `rounded-md` | 標籤、徽章 |
| 8 px | `rounded-lg` | 小按鈕、input |
| 12 px | `rounded-xl` | 一般按鈕、小卡片 |
| **16 px** | **`rounded-2xl`** | **主要卡片（首選）** |
| 24 px | `rounded-3xl` | 大型區塊、hero card |
| 9999 px | `rounded-full` | 頭像、pill badge、圓形 CTA |

### 7.3 陰影 Shadows（暖橘調）
品牌陰影使用 **warm peach tint** 而非灰色，維持溫度：
- `shadow-sm`：`0 1px 2px 0 #FED7AA80`
- `shadow-md`：`0 4px 6px -1px #FED7AA80, 0 2px 4px -2px #FED7AA80`
- `shadow-lg`：`0 10px 15px -3px #FED7AA80, 0 4px 6px -4px #FED7AA80`
- `shadow-xl`：`0 20px 25px -5px #FED7AA80, 0 8px 10px -6px #FED7AA80`

### 7.4 按鈕規範 Buttons

| 類型 | 背景 | 文字 | Hover | 圓角 | 使用 |
|---|---|---|---|---|---|
| **Primary** | `#F75000` | `#FFFFFF` (bold) | `#C4935F` | 12px | 主 CTA（立即預約、填問卷） |
| **Secondary** | `#FFFFFF` | `#F75000` (bold) + 1px border `#F75000` | `#FFF7ED` 填色 | 12px | 次要動作 |
| **Tertiary / Ghost** | 透明 | `#4A4A38` | 底色 `#F0D9BF` | 12px | 導覽、小動作 |
| **Sage Accent** | `#CCD5AE` | `#4A4A38` | `#A8B887` | 12px | 保證章、認證類按鈕 |

**按鈕文案**：動詞 + 結果，搭配箭頭如「立即預約課程 ➔」「填寫問卷 →」

### 7.5 卡片 Cards
- 背景：`#FFFFFF`
- 邊框：1px solid `#E8E4D8`
- 圓角：16px（`rounded-2xl`）
- 內距：24–32px（桌機）、20px（手機）
- 陰影：`shadow-md`（預設）／ `shadow-lg`（hover 或強調）

### 7.6 徽章 / 標籤 Badges
- 圓角：9999px（pill）或 6px
- 內距：4px × 12px
- 字級：12–14px、weight 500
- 範例：
  - 折扣標籤：背景 `#F75000`、文字白
  - 認證章：背景 `#CCD5AE`、文字 `#4A4A38`
  - Tag：背景 `#F0D9BF`、文字 `#4A4A38`

## 8. 語調與文案 Voice & Tone

> 完整細則參見 [`02-MARKETING/STYLE_GUIDE.md`](../02-MARKETING/STYLE_GUIDE.md)。本節是**精要版**，聚焦跨部門共識。

### 8.1 四大語調原則
1. **專業但不冷冰冰** —— 像一位拿到 KPA 認證的訓犬師朋友，不是教科書。
2. **溫暖但不煽情** —— 讓事實說話，不用「心碎 💔」「崩潰 😭」這種情緒渲染。
3. **直接、簡潔、果斷** —— 每段最多 2–3 句；寧多分段，不寫長段。
4. **口語化但不隨便** —— 用「你」「牠」「狗狗」；不用「超讚der」「毛爸毛媽」這類網路／過度親暱用語。

### 8.2 稱呼體系

| 對象 | 稱呼 |
|---|---|
| 狗狗 | **牠**（永遠不用「它」），口語「狗狗」，正式「犬隻」 |
| 讀者／客戶 | **你**（不用「您」，拉近距離） |
| 我方 | **我們**（代表 Dori & Rito 團隊） |
| 訓練方法 | 正向訓練、正向強化、無恐懼訓練 |

### 8.3 用字白名單 / 黑名單

| ✅ 請用 | ❌ 禁止 |
|---|---|
| 改善、陪伴、理解、引導 | 矯正、糾正、壓制、服從 |
| 行為、情緒、反應 | 壞狗、不乖、頑皮、搗蛋鬼 |
| 敏感、焦慮、反應性 | 神經質、有問題、難搞 |
| 牠、狗狗、犬隻 | 它、毛孩子（過度親暱） |
| 你、你的狗狗 | 您、親愛的毛爸毛媽 |
| 科學、研究、證據顯示 | 老師說、聽說、據說 |

### 8.4 標題公式
- **痛點問句** + 重新框架：「你已經試過很多方法了，為什麼還是沒用？」
- **數字承諾**：「5 步驟正向訓練完整指南」「8 大典型表現」
- **保證感**：「100% 無恐懼訓練」「課程安心保證 🛡️」

### 8.5 CTA 文案結構
1. **肯定事實**（降低孤獨感）：「分離焦慮是最常見的行為問題之一。」
2. **同理連結**：「你不是唯一經歷這件事的人。」
3. **行動指引**：「填寫問卷 → 預約諮詢 → 加入 LINE」
4. **信任背書**：KPA / CATCH 認證、客製化
5. **情境收尾**：「特別適合忙碌的上班族。」

### 8.6 官方簽名行
所有文章、電子報、簡報結尾一致使用：

> *Dori & Rito 專業訓犬服務｜KPA & CATCH 認證正向訓練*

## 10. Do's & Don'ts 檢查表

### ✅ 在任何素材送出前檢查：

- [ ] 顏色都使用官方 token（從第 3 節複製）
- [ ] 字體是 Noto Sans TC（或合法 fallback）
- [ ] 文字色 vs. 背景色通過 WCAG AA
- [ ] 稱呼正確：你、牠、我們
- [ ] Emoji 數量在範圍內（文章 ≤ 10、貼文 3–5）
- [ ] 無黑名單用字（矯正、服從、壞狗…）
- [ ] Logo 有足夠 clear space
- [ ] 按鈕用品牌橘 `#F75000`，文案是「動詞＋結果」
- [ ] 附上官方簽名行 / 認證徽章（KPA / CATCH）

### ❌ 請避免：

- ❌ 用純黑 / 純灰 / 寶藍 / 螢光
- ❌ 用 stock photo 直接貼，沒做色調統一
- ❌ Emoji 塞滿句子中間
- ❌ 「立即行動！」「最後機會！」這種行銷式逼迫
- ❌ 「親愛的毛爸毛媽」「超乖狗狗」這類過度親暱
- ❌ 拉伸變形的 logo / 自行配色的 logo
