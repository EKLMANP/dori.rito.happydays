> **案例來源**：阿寶妞（飼主：Selena）｜訓練師：Rito Dori
> **訓練期間**：2025/12/06 ~ 2026/01/25（共 8 週）
> **適用對象**：對人、狗、環境聲音有反應性吠叫行為的小型犬

## 二、訓練計劃總覽（8 週進程）

### 核心訓練策略

1. **減敏與反制約（Desensitization & Counter-Conditioning）**：系統性降低對刺激物的反應閾值
2. **正向連結建立**：讓狗產生「陌生人/狗 = 好康」的連結
3. **壓力管理**：透過豐富化遊戲、舔食墊等降低日常壓力累積
4. **信心建立**：透過嗅聞探索、豐富化遊戲增強自信
5. **衝動控制**：訓練狗在面對刺激時能自我調節
6. **飼主教育**：教導飼主放鬆、正確判讀狗的肢體語言

## 三、每週訓練內容詳細紀錄

### 第一週（12/06）—— 基礎建立 & 壓力管理

**訓練重點：**
1. 戶外鬆繩散步、U-turn 練習：建立良好的散步連結，避免直接面對刺激源
2. 室內牽繩冷靜練習：拉開與刺激源距離 → 狗冷靜 → 按響片 → 獎勵零食（建立「陌生人 = 好康」的正向連結）
3. 豐富化遊戲實作：藏食毛巾、吵鬧百寶箱（建立信心 & 釋放壓力）

**回家作業（核心：減少壓力累積）：**
1. 外出散步降低壓力：遠遠看到人/狗就引導 U-turn 帶開
2. 進電梯：引導狗到角落，飼主背對電梯門面向狗，有人進來前撒一把零食（效果不佳則直接抱起背對鄰居）
3. 豐富化遊戲：毛巾尋寶、吵鬧百寶箱（每天 5-10 分鐘）
4. 舔食墊：每晚散步結束後
5. 白噪音：每天播放鑰匙聲、大力開關門聲、卡車行駛聲等

---

### 第二週（12/13）—— 碰手訓練 & 推車籃正向練習

**訓練重點：**
1. 室內牽繩冷靜練習（進階）：讓狗在有牽繩狀態下自己選擇靠近陌生人 → 冷靜不吠叫 → 好棒 → 零食獎勵（陌生人先站不動，狗冷靜後再做其他動作如蹲下、轉圈）
2. 「碰手」訓練：伸出手指 → 狗用鼻子碰 → 口頭獎勵 → 零食（初期只要看手就獎勵，或手靠近一點）
3. 「紙杯找零食」遊戲：紙杯蓋零食上，說 OK 後讓狗找
4. 進推車籃正向練習

**回家作業（核心：減壓 + 增強自信）：**
1. 持續外出散步降低壓力
2. 碰手練習：家中先練熟 → 加入口頭指令「碰手」
3. 豐富化遊戲：毛巾尋寶、吵鬧百寶箱、紙杯找零食（每天 5-10 分鐘，1-2 種）
4. 舔食墊：每晚散步後
5. 推車籃正向練習（分 5 級）：
   - L1：在家進推車籃 → 口頭獎勵 → 零食
   - L2：在家緩慢蓋上推車籃 → 冷靜 → 獎勵
   - L3：在車上不發動，流程同 L2
   - L4：在車上發動引擎不行駛，流程同 L2
   - L5：開車出門，時間慢慢增加 10 分鐘 → 30 分鐘 → 1 小時

---

### 第三週（12/20）—— 電梯減敏 & 墊子訓練

**訓練重點：**
1. 戶外鬆繩散步、看人減敏練習
2. 1F 大廳減敏練習
3. 電梯減敏練習
4. 「上墊子」練習

**回家作業（核心：外出散步減敏 & 電梯減敏）：**
1. 外出散步：嘗試減敏練習，包含稍微拉近距離、跟在其他狗後面；在附近椅子坐 5-10 分鐘讓狗自己冷靜，不定期給口頭或零食獎勵
2. 電梯減敏練習：進電梯讓狗到角落（縮短牽繩），鄰居進出電梯前瘋狂給零食（或用嗅聞玩具）。**每次練習先抓 5 個鄰居進出後就結束，避免壓力過大**
3. 上墊子練習：狗自己上墊子 → 按響片 → 零食獎勵
4. 持續豐富化遊戲 & 舔食墊

---

### 第四週（12/27）—— 墊子等待 & 大廳減敏

**訓練重點：**
1. 戶外鬆繩散步、減敏練習
2. 1F 大廳減敏練習（使用百寶箱、墊子）
3. 電梯減敏練習（使用百寶箱）
4. 墊子上等待練習
5. 豐富化遊戲 4：鞋盒尋寶

**回家作業（核心：跟著其他狗 & 電梯、大廳減敏）：**
1. 外出散步：遇到其他狗跟在後面進行減敏
2. 電梯減敏：進電梯讓狗到角落，鄰居進出時給百寶箱
3. 大廳減敏：讓狗在大廳待在墊子上，同時給百寶箱
4. 墊子上等待練習：拉長等待時間 → 口頭獎勵 → 零食
5. 持續豐富化遊戲（新增：鞋盒尋寶）

---

### 第五週（01/03）—— 衝動控制 & 門口冷靜

**訓練重點：**
1. 戶外鬆繩散步（牽繩扣胸前）
2. 1F 大廳減敏練習
3. 電梯減敏練習
4. 墊子上衝動控制練習（零食）
5. 門口冷靜練習

**回家作業（核心：衝動控制練習）：**
1. 持續電梯 & 大廳減敏練習
2. 墊子上衝動控制練習：
   - Level 1：零食放手心握拳 → 狗冷靜 → Yes → 獎勵零食
   - Level 2：零食在遠處丟地 → 狗冷靜不暴衝 → Yes → 獎勵零食
3. 持續豐富化遊戲 & 舔食墊

**備註**：下週帶訓練師的狗（多莉）進行狗狗減敏訓練

---

### 第六週（01/10）—— 狗狗減敏 & 長牽繩練習

**訓練重點：**
1. （室外）戶外長牽繩鬆繩散步、與多莉進行減敏練習（主要）
2. （室外）看到其他狗的正向連結練習

**回家作業（核心：媽媽放鬆 & 戶外鬆繩探索嗅聞）：**
1. 長牽繩鬆繩散步練習：到草地面積較大區域鬆繩讓狗自由探索；周圍有其他狗靠近則主動引導拉開距離
2. 看到其他狗的正向連結練習：狗瞄到對方 → 馬上按響片 → 反方向丟零食

---

### 第七週（01/17）—— Watch 指令 & 長牽繩收放

**訓練重點：**
1. （室外）戶外長牽繩散步、與多莉減敏練習（主要）
2. （室內）「Watch」練習

**回家作業（核心：長牽繩收放 & Watch 練習）：**
1. 長牽繩收放散步：人行道窄 → 牽繩收短；空曠人少 → 牽繩放長探索嗅聞
2. 看到其他狗正向連結練習（不暴衝的距離）：狗瞄到對方 → 按響片 → 反方向丟零食
3. 室內「Watch」練習（3 級進程）：
   - Level 1：拿零食放在眼睛高度 → 狗看你眼睛 → 按響片 → 零食
   - Level 2：零食放眼睛高度 → 說「Watch」→ 狗看你 → 按響片 → 零食
   - Level 3：直接下「Watch」指令 → 狗看向你 → 按響片 → 零食
   - **泛化路徑**：家裡練 2-3 天穩定 → 戶外人少車少處 → 人多車多有狗處

---

### 第八週（01/24）—— 影子散步 & 趴下指令 & 結業

**訓練重點：**
1. （室外）戶外長牽繩鬆繩散步、與多莉進行影子散步練習（主要）
2. （室外）看到其他狗的正向連結練習
3. （室內）「Down」（趴下）練習

**未來自主練習重點：**
- 媽媽放輕鬆、漸進式為狗創造各種小成功

**額外指導：訪客來訪減壓指南**（提供圖文指南）

## 四、訓練技術與工具總整理

### 4.1 核心訓練技術

| 技術 | 說明 | 應用情境 |
|------|------|----------|
| **U-turn（迴轉）** | 看到刺激源時引導狗轉向離開 | 散步遇到人/狗 |
| **減敏（Desensitization）** | 系統性、漸進式暴露於刺激源，逐步縮短距離 | 電梯、大廳、散步遇狗 |
| **反制約（Counter-Conditioning）** | 將原本引發恐懼的刺激與正向獎勵配對 | 陌生人 = 零食、其他狗 = 零食 |
| **響片訓練（Clicker Training）** | 精準標記正確行為的瞬間 | 所有正向行為標記 |
| **碰手（Touch/Target）** | 教狗用鼻子碰手，作為注意力轉移工具 | 散步中轉移注意力 |
| **Watch（看我）** | 教狗在指令下注視飼主眼睛 | 散步中控制注意力方向 |
| **墊子訓練（Mat Training）** | 教狗將墊子視為安全基地，在上面保持冷靜 | 大廳等待、訪客來訪、室內冷靜 |
| **衝動控制（Impulse Control）** | 教狗在誘惑前保持冷靜才能獲得獎勵 | 面對刺激時的自我調節 |
| **影子散步（Shadow Walking）** | 跟在另一隻狗後方保持安全距離同行 | 狗狗減敏練習 |
| **正向連結練習** | 狗瞄到刺激物 → 按響片 → 反方向丟零食 | 看到其他狗時 |
| **鬆繩散步** | 牽繩保持鬆弛的散步方式，讓狗自由探索 | 日常散步 |
| **長牽繩收放** | 窄處收短、寬處放長，讓狗有適當探索空間 | 不同環境散步 |

### 4.2 豐富化遊戲清單

| 遊戲名稱 | 說明 | 功能 |
|----------|------|------|
| **藏食毛巾** | 零食包在毛巾內讓狗用嗅覺和前腳找出 | 嗅聞刺激、壓力釋放 |
| **吵鬧百寶箱** | 零食藏在會發出聲音的物品中（如空瓶罐） | 建立對新奇聲音的信心、壓力釋放 |
| **紙杯找零食** | 紙杯蓋在零食上，指令後讓狗翻找 | 問題解決能力、自信心 |
| **家裡尋寶** | 零食藏在家中各處讓狗嗅聞尋找 | 嗅聞刺激、環境探索 |
| **鞋盒尋寶** | 零食藏在鞋盒中讓狗自行打開 | 問題解決能力、自信心 |
| **舔食墊** | 將濕食/花生醬等塗在舔食墊上讓狗舔食 | 散步後放鬆、降低壓力 |
| **漏食玩具** | 讓狗透過推動/翻轉取得零食 | 獨處時的心理刺激 |

**使用建議**：每天 5-10 分鐘，每天玩 1-2 種；舔食墊建議每晚散步後給

### 4.3 使用工具清單

- 響片（Clicker）
- 墊子（Mat）
- 一般牽繩 & 長牽繩
- 胸背帶（牽繩扣胸前）
- 推車籃
- 舔食墊
- 百寶箱（吵鬧箱）
- 白噪音播放器/手機

## 五、分級訓練進程設計模板

### 5.1 電梯減敏進程

```
階段 1：進電梯引導到角落，飼主背對門面向狗，撒零食
階段 2：鄰居進出時瘋狂給零食或百寶箱（每次限 5 人進出就結束）
階段 3：使用墊子在電梯中，狗能冷靜注視進出的人
```

### 5.2 推車籃/車上正向練習進程

```
L1：在家進推車籃 → 獎勵
L2：在家緩慢蓋上推車籃 → 冷靜 → 獎勵
L3：在車上不發動 → 流程同 L2
L4：在車上發動引擎不行駛 → 流程同 L2
L5：開車出門 → 時間漸增（10 分鐘 → 30 分鐘 → 1 小時）
```

### 5.3 Watch 指令訓練進程

```
L1：拿零食放眼睛高度 → 狗看你眼睛 → 響片 → 零食
L2：零食放眼睛高度 → 說「Watch」→ 狗看你 → 響片 → 零食
L3：直接下「Watch」→ 狗看向你 → 響片 → 零食
泛化：家中（2-3 天）→ 戶外人少處 → 人多有狗處
```

### 5.4 衝動控制訓練進程

```
L1：零食放手心握拳 → 狗冷靜 → Yes → 獎勵
L2：零食在遠處丟地 → 狗冷靜不暴衝 → Yes → 獎勵
```

### 5.5 室內牽繩冷靜練習進程

```
階段 1：拉開與陌生人距離 → 狗冷靜 → 響片 → 零食
階段 2：狗有牽繩狀態下自己選擇靠近陌生人 → 冷靜 → 獎勵
階段 3：陌生人站著不動 → 狗冷靜 → 陌生人開始做其他動作（蹲下、轉圈）
```

## 六、8 週訓練進程時間軸

```
第 1 週：基礎建立
  ├── U-turn 練習
  ├── 室內牽繩冷靜練習（響片 + 零食正向連結）
  ├── 豐富化遊戲啟動（藏食毛巾、百寶箱）
  ├── 舔食墊引入
  └── 白噪音播放

第 2 週：技能擴展
  ├── 碰手（Touch）訓練
  ├── 紙杯找零食遊戲
  ├── 推車籃正向練習（5 級進程）
  └── 室內牽繩冷靜練習（進階：狗自己選擇靠近）

第 3 週：場景減敏啟動
  ├── 戶外看人減敏
  ├── 1F 大廳減敏
```

## 八、關鍵成功因素 & 注意事項

### 飼主面

- **飼主配合度極高**：每次上課兩人一起（飼主與妹妹），作業執行度佳
- **飼主放鬆的重要性**：多次強調「媽媽放輕鬆」，飼主的緊張會透過牽繩傳遞給狗
- **紀錄習慣**：使用 Google 表單每天紀錄狗的行為變化，有助於追蹤進步

### 訓練面

- **壓力管理優先**：前期核心重點放在減少壓力累積，而非直接矯正行為
- **漸進式進程**：每個技能都有清晰的分級（L1 → L2 → L3...），不跳級
- **避免過度刺激**：電梯練習限制每次 5 個鄰居進出就結束
- **豐富化遊戲的角色**：不只是附加活動，而是核心壓力管理工具
- **使用友善狗做減敏**：第 5 週起帶訓練師的狗（多莉）進行狗狗間減敏
- **環境管理**：白噪音降低獨自在家時的環境刺激
- **泛化訓練**：所有指令都有從室內 → 室外低刺激 → 室外高刺激的泛化路徑

### 針對此犬種/類型的考量

- **迷你杜賓特性**：警覺性高、能量高，需要充足的心理刺激
- **手術史影響**：因多次手術導致社會化窗口期錯過，需更耐心地進行減敏
- **食物動力高**：可善用食物獎勵作為主要訓練工具
- **恢復速度快**：刺激消失後能很快冷靜（非深層焦慮），訓練預後佳

## 九、適用於類似案例的快速參考

### 適用條件

- 小型犬
- 反應性吠叫（非攻擊性）
- 對人/狗/環境聲音有過度反應
- 食物動力佳
- 刺激消失後能快速恢復冷靜
- 飼主配合度高
